# Publishing

Share your documentation with the world in one click.

## Public Hosting

Each project can be published with a single toggle in **Project Settings**. Once enabled, your docs are live at:

```
/p/[project-id]
```

Published docs include:
- Full sidebar navigation
- Full-text search (Cmd+K)
- Wiki links resolved between pages
- SEO metadata (Open Graph, Twitter Cards)
- Sitemap for search engines

## Custom Domain

Pro plan users can point their own domain to their documentation.

1. Go to **Project Settings**
2. Enter your domain in the **Custom Domain** field
3. Add a CNAME record pointing to `tomebase.io`
4. SSL certificates are provisioned automatically

Propagation can take up to 24 hours.

## SEO

Each page automatically gets:
- Title and description meta tags
- Open Graph tags for social sharing
- Twitter Card tags
- Canonical URL
- Automatic sitemap generation

## Sharing

Every published page has a **Copy Link** button in the top nav bar. Click it to copy the current page URL to your clipboard.
