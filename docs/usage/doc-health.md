# Doc Health

Keep your documentation healthy with automated quality scanning.

## Health Score

Each project gets a health score (0–100%) based on:

- **Link quality** — broken wiki links reduce the score
- **Freshness** — stale pages (not updated in 30+ days) reduce the score
- **Engagement** — pages with low view counts reduce the score
- **Content quality** — empty pages reduce the score

## Scans

The health dashboard scans for five types of issues:

| Issue | Description |
|-------|-------------|
| Broken Links | Wiki links pointing to pages that don't exist |
| Orphans | Pages that no other page links to |
| Empty Pages | Pages with no content |
| Stale Pages | Pages not updated in 30+ days |
| Low Engagement | Published pages with fewer than 5 views |

## Fixing Issues

Each issue in the health report links directly to the affected page. Common fixes:

- **Broken links** — create the missing page or update the link
- **Orphans** — add wiki links from related pages
- **Empty pages** — write content or remove the page
- **Stale pages** — review and update the content
- **Low engagement** — promote pages or consolidate with related content
