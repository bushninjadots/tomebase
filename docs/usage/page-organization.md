# Page Organization

Structure your documentation with hierarchical pages, tags, and visual connections.

## Page Hierarchy

Pages can be nested as parent-child relationships. Use the sidebar controls to organize:

- **Move up/down** — reorder pages within the same level
- **Indent/outdent** — nest or unnest pages
- **Drag-free** — all controls are button-based, no drag-and-drop needed

Breadcrumbs at the top of each page show the full path.

## Tags

Tags are extracted from page content automatically. Write `#tag` anywhere in your content and it appears in the sidebar filter. Click a tag to show only pages with that tag.

## Backlinks

The editor footer shows every page that links to the current page via wiki links. This helps you understand how pages relate and find pages that need updating when content changes.

## Graph View

Click **Graph View** in the sidebar to see a force-directed visualization of all connections between pages. Features:

- **Local mode** — highlights the current page's direct connections
- **Global mode** — shows every link in the project
- **Draggable nodes** — rearrange the graph manually
- **Zoom controls** — zoom in/out and pan
- **Search** — filter nodes by title
- **Click to navigate** — click any node to go to that page

## Doc Health

The **Health** tool scans your project for quality issues:

- Broken wiki links
- Orphan pages (no other pages link to them)
- Empty pages (no content)
- Stale pages (not updated in 30+ days)
- Low-engagement pages (published with few views)

Each issue links directly to the affected page so you can fix it.
