# Getting Started

Create your first project, write a page, and publish it to the web in under 5 minutes.

## 1. Create a Project

From the dashboard, click **New Project**. Give it a name and optionally pick a starter template:

- **Blank Project** — start from scratch
- **API Documentation** — pre-creates Getting Started + API Reference pages
- **Internal Wiki** — pre-creates Home + Getting Started pages
- **Product Documentation** — pre-creates Overview + Getting Started + Troubleshooting pages

## 2. Write a Page

Select your project to open the editor. Click **New Page** in the sidebar or use `Cmd+K` and search for "new page". Write in Markdown with live preview. The editor auto-saves every 2 seconds.

## 3. Publish

Open **Project Settings** from the sidebar. Toggle **Publish** on. Your docs go live immediately at a public URL you can share with anyone.
