# Roadmap

## Milestone 1: MVP (Current)
- [x] Monorepo foundation (Turborepo, workspaces)
- [x] Shared packages (ui, utils, types, database, ai, config)
- [x] Landing page with marketing content
- [x] Authentication (GitHub, Google via NextAuth)
- [x] Dashboard with project management
- [x] Documentation viewer and editor
- [x] AI chat over documentation
- [x] Pricing and features pages

## Milestone 2: Launch
- [ ] Auto-generation of API docs from code repositories
- [ ] API playground with interactive testing
- [ ] MDX support with custom components
- [ ] Version history and diff viewing
- [ ] Team collaboration (comments, suggestions)
- [ ] Email/password authentication
- [ ] Documentation search (semantic + keyword)

## Milestone 3: Growth
- [ ] API for programmatic access
- [ ] GitHub/GitLab integration (auto-sync docs)
- [ ] Webhook notifications
- [ ] Custom domains
- [ ] Analytics dashboard
- [ ] Public documentation hosting
- [ ] Stripe subscription billing

## Milestone 4: Scale
- [ ] Enterprise SSO (SAML, OIDC)
- [ ] Audit logs
- [ ] Role-based access control
- [ ] Self-hosted deployment (Docker Compose)
- [ ] Multi-region edge delivery
- [ ] SOC 2 compliance
- [ ] SLA guarantees

## Milestone 5: Platform
- [ ] Plugin/extension system
- [ ] Marketplace for templates
- [ ] AI-powered doc generation from code
- [ ] Knowledge graph visualization
- [ ] API monitoring and status pages
- [ ] Network effects: community docs, discovery
