# Changelog

## 0.1.0 (Current)

### Added
- Monorepo foundation with Turborepo and npm workspaces
- Shared packages: ui, utils, types, database (Prisma), ai, config
- Next.js 15 web app with App Router
- Landing page with premium design
- Authentication with NextAuth v5 (GitHub, Google)
- Dashboard for project management
- Documentation viewer and Markdown editor
- AI chat interface for documentation Q&A
- Pricing and features marketing pages
- SQLite database with Prisma ORM
- Tailwind CSS v4 styling
- Comprehensive project documentation

### Architecture
- Clean Architecture with separated concerns
- Package-based monorepo for reusability
- TypeScript strict mode throughout
- Server components by default with client islands
